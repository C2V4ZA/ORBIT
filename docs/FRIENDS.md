# Friends & private messages

## Friend code vs. Orbit ID

| | Friend code | Orbit ID |
|---|---|---|
| Looks like | `EZB3C-R2AGP-9GGSD-DZDAQ` (20 characters) | `PQ96-D2FM-5DBS` (12 characters) |
| Purpose | **Reaching** your PS3 – contains its network address and the key of your friend inbox | **Recognising** you – derived from your PS3's own identity key |
| Changes? | Can change when your network address changes (ORBIT updates it) | Stays the same, even when you change your name |
| Share it? | Yes, with people you want as friends | Yes – compare it to make sure you added the right person |

Finding someone by Orbit ID alone would need a central directory server. ORBIT has none, so friends are added with the friend code.

## Adding a friend

1. **Friends › Your friend code** – send it to your friend (phone, chat, read it out).
2. Your friend: **Friends › Add Friend** and types the code.
3. You: the request appears under **Friend requests** – ✕ accept, □ decline.
4. Both PS3s now connect to each other in the background: you see each other's online status, profile and shared servers.

## What you can do with a friend

| | |
|---|---|
| ✕ | Write a private message |
| SELECT | Call (voice chat in your private conversation) |
| △ | Add them directly to one of **your** servers |
| ○ | Remove friend, block |

## Private messages

- **One-to-one** and **group conversations** (Messages › New group chat, pick friends).
- **Reply**, **edit** your own messages, **delete**, **6 reactions** (❤ 😂 ★ ✓ ☺ ♪) – via message mode (L2).
- **Search** in a chat, **mute** a chat, **timestamps**, unread markers.
- A private chat is hosted on the PS3 of the person who started it.

## Offline messages

If the PS3 hosting a chat is offline, your message is kept **on your PS3** and shown as *“Waiting for delivery – not delivered yet”*. ORBIT delivers it automatically as soon as that PS3 is reachable again. Up to 32 messages can wait. There is **no** central server that stores messages for you.

## Blocking

Blocking removes the person from private chats hosted on your PS3, stops their friend requests (they only see “pending”) and hides their messages in servers. Unblocking removes the entry completely – you would need to become friends again.

## Status

Online · Away · Busy · Invisible (others see you as offline) – plus a custom status text, set in **Settings › Profile**.
