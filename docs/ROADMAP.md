# Roadmap

[← Back to README](../README.md)

> Everything on this page is **planned or being researched – not implemented**. There are no promised dates. Order and scope can change.

### 🎮 PlayStation 4
- [ ] ORBIT client for PS4 with GoldHEN
- [ ] Chat and voice between PS3 and PS4
- [ ] Further research on controller audio

### 🌍 Languages
- [ ] More interface translations
- [ ] Better font coverage (e.g. Japanese, Korean, Chinese)

### 👤 Profiles
- [ ] More profile options
- [ ] Extended presence features

### 🛰️ Servers
- [ ] More server customisation
- [ ] Additional moderation options
- [ ] Connecting to a server by IP address or QR code

### 💬 Communication
- [ ] Better notifications
- [ ] More message features
- [ ] Better network reliability

### 🔭 Long-term research
- [ ] Cross-platform communication
- [ ] Advanced voice functionality (e.g. voice in the background while playing – needs a system plugin; feasibility unknown)
- [ ] Game streaming experiments

Ideas and wishes: open a [feature request](https://github.com/C2V4ZA/ORBIT/issues/new/choose).
