# Community servers

[← Back to README](../README.md)

A server is a community with categories, text channels, voice channels and roles. It **lives on the PS3 that created it** (the host). While ORBIT runs there, everyone can use it; when the host is offline, the server shows *Host offline* and messages written meanwhile wait on the writer's PS3.

## Creating a server

**Servers › Create Server**

- **With template:** INFORMATION (welcome, rules, announcements), COMMUNITY (general, ps3-games, screenshots, off-topic), VOICE CHANNELS (General Voice, Gaming Room, Private Lounge). Default names are created in your interface language – after that they are your content and are never translated.
- **Simple:** one text and one voice channel.

## Inviting

△ shows a 20-character invite code. Friends can also be added directly (Friends › △). Servers marked **public** can be joined without a code by people connected to your PS3 (Servers › Public servers) – there is no worldwide server list.

## Server settings (○ › Server settings)

| Setting | |
|---|---|
| Name, description, welcome message | Shown on the server overview |
| Icon, colour, banner | Design of the server |
| Public | Connected PS3s can join without a code |
| Categories & channels | Create, rename, describe, move up/down, change category, delete |
| Who can see / write | Restrict channels to roles (private channels, announcement channels) |
| Roles & permissions | See below |
| Members, banned people | Roles, mute, remove, ban, unban |
| New invite code | Old codes stop working |

## Roles & permissions

Default roles: **Owner**, **Admin**, **Moderator**, **Member** – plus up to 8 roles in total, each with a name, colour, rank and permissions.

The 10 permissions: manage server · manage channels · edit roles · invite people · send messages · delete messages · remove members · ban members · manage voice channels · mute members.

- Nobody can give out permissions they don't have, or act on someone with an equal or higher rank. The owner can always do everything.
- **All permission checks run on the host PS3.** Hiding a menu item is only convenience; the host refuses the action itself.

## Limits per PS3

48 slots for servers, private chats and the friend inbox together · 32 people · 16 channels and 8 categories per server · 8 roles per server · 512 stored messages in total (oldest are dropped).
