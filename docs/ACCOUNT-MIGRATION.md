# ORBIT has a new official GitHub account

[English](#english) · [Deutsch](#deutsch) · [Français](#français) · [Español](#español)

## English

ORBIT was originally published under the GitHub account **C2V3ZA**.

Access to that account was lost because of a problem with the e-mail address connected to it. Access could not be recovered, and the old account **C2V3ZA has since been deleted**. To keep ORBIT available, the creator had to create a new GitHub account.

**The new official account is [C2V4ZA](https://github.com/C2V4ZA).**

- This is the **same project by the same creator** – not an unofficial fork, not a copy and not an impersonation.
- ORBIT is **still maintained** by its original creator and has **not been abandoned**.
- The repository has been rebuilt and improved: source code, documentation in four languages, installation guides, real screenshots and both official releases (0.9.5 and 1.0.3).

Please note: this is a statement by the creator. GitHub has not independently verified the connection between the old and the new account. Download ORBIT only from **https://github.com/C2V4ZA/ORBIT** and compare the SHA-256 checksums published on the release pages.
