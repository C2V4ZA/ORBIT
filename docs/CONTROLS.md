# Controls

[← Back to README](../README.md)

ORBIT is made for the controller. Every connected controller can steer.

## Main screen

| Button | Action |
|---|---|
| **◀ ▶** (D-pad) | Switch section: Home · Friends · Messages · Servers · Settings |
| **▲ ▼** (D-pad) | Move through the list on the left |
| **✕** | Open / write a message / OK. On a friend request: accept |
| **○** | Menu (on a friend: friend menu). While replying/editing: cancel |
| **△** | Invite (server/channel). On a friend: invite to one of your servers |
| **□** | Enter an invite code. On a friend request: decline |
| **SELECT** | Join / leave voice chat. On a friend: call |
| **R2** | Mute / unmute your microphone (works everywhere) |
| **L1 / R1** | Scroll older / newer messages |
| **L2** | Message mode (see below) |
| **R3** | Show / hide the FPS counter |
| **START** | Quit ORBIT |
| **PS button** | Opens the XMB on top of ORBIT – chat and voice keep running underneath |

## Message mode (L2)

| Button | Action |
|---|---|
| **▲ ▼** | Pick a message |
| **✕** | Actions: reply, react, edit (your own), delete (your own, or with the *Delete messages* permission) |
| **△** | React directly (6 reactions) |
| **○ / L2** | Leave message mode |

## On-screen keyboard

| Button | Action |
|---|---|
| **D-pad** | Move over the keys |
| **✕** | Type the key |
| **□** | Delete (hold to delete quickly) |
| **△** | Space |
| **L1 / L2** | Upper / lower case |
| **R1** | Switch layout: German · English · French · Spanish |
| **START** | Send / done |
| **○** | Cancel (a message draft is kept) |

Invite and friend codes get their dashes automatically.
